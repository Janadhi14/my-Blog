## Vectors and scalars

## subscript 
x_t = q(x_t | x_{t-2})

- **x_t** is some value or state at time **t**
- **q(x_t | x_{t-2})** means "the probability distribution of x_t given x_{t-2}"

**The value at time t depends on (or is determined by) the value from time t-2.**

This type of relationship might appear in contexts like:

- **Diffusion models** (where you're gradually adding or removing noise)
- **Time series analysis** (where today's value depends on what happened two days ago)
- **Markov processes** with longer memory (though typically they only look back one step)

## Norm
```python
||v|| = sqrt{v_1^2 + v_2^2 + ... + v_n^2}
```
A **norm** is just a way to measure the "size" or "length" of a vector. Think of it like measuring how far you are from the origin (0,0,0...).
