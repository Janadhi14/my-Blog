## What is powershell and why you need it?
- **PowerShell** is a **command-line shell** and **scripting language** developed by Microsoft.
- It helps you automate tasks and manage windows computers through scripts and commands
- It helps you **automate repetitive tasks** like managing files, users, or software installations.
    
- You can control **Windows system settings** and interact with other software or servers.
    
- It's great for **system administrators**, IT professionals, and anyone who wants to make computer tasks easier.
    
- PowerShell scripts can save you a lot of time once you learn how to use it.
