## What is Generative AI security 
- There is a communication that exists between your Application (front facing product) and the back end Gen AI model (run on the cloud)
- you generally can use a pretrained model 
	- we have some private data that we can use to train our models on so we can increase the speicalization of the output
- Vector enabled Database 
	- example:
	- You could use a vector database to search semantically, so a query like:

> "spicy Sri Lankan chicken dish"

...would return your "Devilled Chicken" or "Chicken Curry" — even if the exact words don’t match.
