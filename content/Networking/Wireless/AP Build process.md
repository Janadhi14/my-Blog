## **Data Collection (Survey Existing APs)**

**Before removing any APs:**

1. **Survey one floor at a time** - Start at one end and work systematically
2. **Scan each existing AP's QR code** using a barcode scanner
    - This captures: AP name, MAC address, outlet number
    - Use the notes app or spreadsheet
3. **Document the data in order:**

```
  AP-Name: FXXX-F1-GOD-101, MAC: XX:XX:XX, Outlet: A-12
```
4. **Complete the entire floor survey of the old aps, before removal** - This prevents confusion if labels fall off or become damaged

## **Label Generation**

1. **Open the label generation spreadsheet**
2. **For each AP:**
    - Keep the existing **AP Name** (same as old AP)
    - Keep the existing **Outlet Number** (same as old AP)
    - Replace with **NEW MAC address** with a MacAddress of a New AP from the box
3. **Generate all labels for that floor** at once using the Dymo label maker
4. **Organize labels in the same order** as the physical AP locations()

## **Physical Replacement**

**Now go back to install:**

1. **Work in the same systematic order** (same direction as survey)
2. **At each location:**
    - Remove old AP
    - Mount new AP (same location/outlet)
    - Apply the pre-printed label to new AP
    - Plug into the **same outlet** documented earlier
    - Verify AP powers on
- Compare teh outlet 
1. **Cross off each location** as completed
