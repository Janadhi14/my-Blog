## Password less authentication methods

### FIDO2 security Key 
FIDO2 enables password less login and enhances security by using public-key cryptography.
- Assymetric cryptography for user authenticayion
- user has a physical device (USB or NFC)
- Authentication sequence 
- provide username -> cryptographic challenge --> use IFDO2 key to sign challange--> service verifies response and grands access 
### Windows Hello 
An biometric authentication feature built into windows 10+, replaces passwords with strong 2 factor authentication on PCs and mobile devices eg: 
	- **Facial recognition**
	- **Fingerprint**
	- **PIN (Personal Identification Number)**
- allows users authenticate to:
	- A Microsoft account
	- An active directory account 
	- an Entra ID account
- Identity Provides Service Or 
- Relying party services that support Fast ID online (FIDO) v2.0 authentication
- Windows hello is for personal devices and uses a pin or biometric gesture where as windows hello for business leverages key based or certificate0-based authentication
both are password-less

Windows hello for business solves:
	- Certificate-based or Key-based
	- Strong passwords can be difficult to remember and users often reuse passwords on multiple sites 
	- Server breaches can expose symmetric network credentials (passwords)
	- Passwords are subject to replay attacks 
	- Users can inadvertently expose their passwords due to phishing attacks
	- can be managed via inTune
- **Windows Hello** = convenience for home users.
- **Windows Hello for Business** = **secure, scalable, password-less** solution for organizations


### OATH token and how it works?
- OATH (Open Authentication) is an open standard that specifies how time-based, one-time passwords(TOTP) codes are generated - 6 digit code 
- Software OATH tokens- typically applications eg Microsoft authentication App

Hardware OATH tokens 
- Small hardware devices that look like a key fob that displays a code that refreshes ever 30 to 60 seconds, with secrete key /seed pre-programmed

## Describe MFA 
- Single sign on means a user doesn't have to sing into every application they use 
- The user logs in once and that credential is used for multiple apps
- Single sogn on base dAuthentication systems are called modern authnetication systems
MFA works by requring 2 or more of the follwing authentication methods:
- something you know (pin or password)
- something you have (trusted device)
- something you are (biometric)
Conditional access will play a central role in facilitating granular MFA 


### Describe self-service password reset 
- A feature of Entra ID that allows users to change or reset their password, without administrator or help desk involvement(convenient because it is the most common helpdesk request)
- Azure AD SSPR facilitates:
	- password change -  when a user knows their password but wants to change it to something new 
	- password reset - when a user cant sing in, such as when they forget the password and reset it 
	- password unlock -  when a user can't sign in because their account is locked 
- saves time and money and improves productivity and security 
### Entra ID Password protection and management 
- Reduces the risk of users setting weak passwords by detecting and blocking known weak passwords and their variants 
- Global banned passwords- list of known weak passwords that is automatically updated and enforced by Microsoft
- Custom banned password lists
- Protect against password spray attacks - blocks all known weak passwords likely to be used in these attacks based on real-world security telemetry data from Entra-ID 
- Provides hybrid security
