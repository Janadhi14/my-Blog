## Vector
- **In ML:** Feature vectors represent data points (e.g., [height, weight, age])
- **Vector representation:** v = [v₁, v₂, v₃, ..., vₙ]
- **Geometric interpretation:** Arrows in space pointing from origin to a point
#### Essental Operations
- **Vector Addition:** v + w = [v₁+w₁, v₂+w₂, ..., vₙ+wₙ]
- **Scalar Multiplication:** cv = [cv₁, cv₂, ..., cvₙ]
- **Dot Product:** v·w = v₁w₁ + v₂w₂ + ... + vₙwₙ
- **Vector Norm (Length):** ||v|| = √(v₁² + v₂² + ... + vₙ²)

## Conditional Probability 
- Conditional probability is the probability of an event occurring given that another event has already occurred. It's written as P(A|B), read as "the probability of A given B."
	- eg: P(Output | Input)

- **Simple Example:** Imagine you're drawing cards from a standard deck:

- P(drawing a King) = 4/52
- But P(drawing a King | the card is red) = 2/26 = 1/13

**Independence:** When events are independent, P(A|B) = P(A). Knowing B occurred doesn't change the probability of A. For example, coin flips are independent - knowing the first flip was heads doesn't change the probability that the second flip is heads.

**Chain Rule:** Conditional probability leads to the chain rule: P(A and B) = P(A|B) × P(B), which is incredibly useful for calculating joint probabilities in complex scenarios.
