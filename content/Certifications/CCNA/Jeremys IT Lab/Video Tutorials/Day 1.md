## Client-server model 
- A client is a device that accesses a service made available by a server 
- A server is a deice that provides functions or services for clients 
- Devices can act as both a client and a server 
## Switches 
This is a "Dumb device" that functions to send network traffic to a specifiec location

## Routers 
- Routers have fewer network interfaces than switches 
- Routers are used to provided connectivity between LANs and therefore used to send Data over the internet 
## Firewall
A firewall is used to protect networks
- these are specialty network traffic protecting devices, they monitor and control network traffic based on the rules that are configured. 
- Firewalls must be configured with security rules to determine what traffic is allwed and denied 
- Cisco firewalls - firepower 2100 (next gen firewall)
	- Asa5500-X classic cisco firewalls
	- Next gen fire firewalls include ips (intrusion prevention system)
- Next generation firewalls have modern and advanced filtering capabilities 
- Software firewalls?
	- These are host based firewalls that are software applications that filter traffic entering and exiting a host machine like a PC
