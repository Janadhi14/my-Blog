## Detailed Project Management in Hamina
Hamina provides robust project management capabilities, allowing users to efficiently organize, access, and create wireless network designs and survey data. This is crucial for maintaining a clear overview of multiple projects and collaborating effectively.

### Opening an Existing Project
Hamina allows users to open and manage existing projects, which is essential for continuing work, reviewing past surveys, or making updates. The interface for accessing projects varies slightly depending on the device:

*   **iPad and MacBook:** On these devices, Hamina typically displays project folders, providing a structured way to organize and navigate through multiple projects. This allows for easy access to different client projects, building designs, or survey iterations.
*   **iPhone:** Due to screen size limitations, project folders may not be explicitly shown on iPhones. Users might access projects through a simplified list or a search function.
*   **Tip: Use unique names for each project:** This best practice is vital for efficient project management. Unique and descriptive project names prevent confusion, especially when dealing with multiple sites, different phases of a project (e.g., pre-deployment vs. post-deployment), or various design iterations. Clear naming conventions also facilitate quick searching and retrieval of specific projects.

### Creating a New Project
Creating a new project in Hamina is the first step in designing a new wireless network or conducting a site survey. The process is streamlined to get users started quickly:

1.  **Create a new project:** This initiates a new workspace within Hamina. Users typically provide a project name and potentially other high-level details at this stage.

2.  **Import a floor plan:** This is a fundamental step for any wireless design or survey. Hamina supports importing various floor plan formats, allowing users to upload their building layouts. Hamina's AI-powered features can assist with this, including automatic wall, scope, and scale detection, making the process faster and more accurate. Importing existing floor plans from other systems (like Cisco Meraki or Juniper Mist) is also often supported, allowing for seamless integration with existing network infrastructure data.

3.  **Set the scale:** Accurately setting the scale of the imported floor plan is paramount for precise wireless design and survey data. The scale ensures that distances, wall attenuations, and access point placements are correctly represented in the software. Hamina may offer features to automatically detect the scale from the floor plan or allow for manual input. For instance, if a floor plan includes a known measurement (e.g., a wall that is 10 meters long), users can use a measurement tool within Hamina to define this distance on the digital map, and the software will then calculate the overall scale. This step is critical for generating accurate heatmaps and predictive models.
