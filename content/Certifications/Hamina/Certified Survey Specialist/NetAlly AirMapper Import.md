## Detailed NetAlly AirMapper Import
The NetAlly AirMapper application is a powerful site survey tool available on NetAlly's handheld network testers, such as the AirCheck G2, EtherScope nXG, and CyberScope. It allows network professionals to perform efficient and accurate Wi-Fi site surveys, collecting crucial data about the wireless environment. The ability to import this data into Hamina Network Planner significantly enhances the workflow for wireless network design and analysis.

### What is NetAlly AirMapper?
NetAlly AirMapper is a software application that runs on NetAlly's portable network analysis tools. It enables users to:

*   **Conduct Site Surveys:** Perform active and passive surveys to measure Wi-Fi signal strength, noise, interference, and other key performance indicators.
*   **Create Heatmaps:** Generate real-time heatmaps on the handheld device, providing immediate visual feedback on Wi-Fi coverage.
*   **Collect Data:** Capture comprehensive data about access points, SSIDs, channels, and client performance.
*   **Ease of Use:** Designed for simplicity, allowing for quick and easy site surveys in various environments.

### The Integration with Hamina Network Planner
The integration between NetAlly AirMapper and Hamina Network Planner is a significant development in the wireless industry, as it allows for seamless data transfer and collaborative workflows between two leading vendors. This integration typically works as follows:

1.  **Data Collection with AirMapper:** A network engineer uses a NetAlly handheld device with AirMapper to perform a site survey, collecting all necessary Wi-Fi data on-site.
2.  **Upload to Link-Live:** The collected survey data is then uploaded from the NetAlly device to NetAlly's cloud-based service, Link-Live. Link-Live acts as a central repository for test results and survey data.
3.  **Import into Hamina Network Planner:** From within Hamina Network Planner (specifically, a Hamina Network Planner Plus subscription is often required), users can import the survey data directly from their NetAlly Link-Live account. This process brings the floor plans, access point locations, and all the collected RF data into Hamina.

### Benefits of the Integration
This integration offers several key benefits for wireless network professionals:

*   **Enhanced Workflow:** Streamlines the process from data collection in the field to in-depth analysis and design in the office. This eliminates the need for manual data transfer or conversion, saving time and reducing errors.
*   **Comprehensive Analysis:** Combines the robust data collection capabilities of NetAlly AirMapper with the advanced design, simulation, and reporting features of Hamina Network Planner. This allows for a more thorough analysis of the wireless environment.
*   **Accurate Design Refinement:** The real-world data from AirMapper can be used to validate and refine predictive designs in Hamina, ensuring that the final network deployment is optimized for actual environmental conditions.
*   **Collaboration:** Facilitates collaboration among teams, as survey data can be easily shared and accessed within the Hamina platform.
*   **Vendor Interoperability:** This integration is a prime example of how different vendors in the wireless ecosystem can work together to provide more complete solutions for network professionals, offering flexibility and choice in tools.
