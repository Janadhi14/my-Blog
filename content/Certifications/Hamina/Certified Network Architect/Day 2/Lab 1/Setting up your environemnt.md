 ## Getting Started with Hamina Wireless Design

## Overview

Lab 1 introduces students to the basic navigation and project setup features of Hamina Network Planner, focusing on creating projects, uploading floor plans, and learning essential map navigation controls.

## Key Learning Objectives

- Create and configure a new Hamina project
- Upload and scale floor plan images
- Master map navigation controls (panning, zooming)
- Set accurate scale measurements for floor plans

## Main Activities

### 1. Project Creation

- **Option 1**: New users create a free account and upgrade using provided license key
- **Option 2**: Existing users create a new project directly
- Project setup: Name "Hospital" in "Hamina Training" folder

### 2. Map Navigation Training

- Upload Hospital.pdf floor plan via drag-and-drop
- Learn navigation controls:
    - **Panning**: Hold Space + mouse movement (recommended method)
    - **Zooming**: Ctrl/Cmd + scroll wheel or trackpad pinch-to-zoom
- Practice exercise: Find three "Mursu" (walruses) on the uploaded map

### 3. Scale Setting

- Use the Scale tool to set accurate measurements
- Click on scale reference points (0 to 10 meters)
- Input correct measurement (10 meters) and confirm
- **Best Practice Note**: Use long distances for accuracy - avoid short measurements like doorways

## Important Technical Notes

- Drag-and-drop currently supports single files only
- Space key + mouse is the recommended panning method
- Accurate scaling is critical for design precision
- Scale should be set using longer reference distances when possible

## Skills Developed

- Basic Hamina interface navigation
- Project management fundamentals
- Floor plan import and scaling procedures
- Map navigation proficiency
